How to Use

Getting Started

  1. Each player bookmarks their own link — don't share the wrong one
  2. Fill in your character info, hit 💾 Save — it saves in your browser
  3. Also download a .json backup after each session — just in case
  4. If you ever switch devices, use 📥 Import to load your backup

🎁 DM Item & Gold Transactions

DM side Open your sheet → go to DM Panel tab → select the player → add gold or items → click Export Gift File → a .json file downloads
Player side Receive the .json file via Discord / iMessage / email → open your sheet → click 🎁 Receive from DM → select the file → inventory and gold update automatically
