DM Setup Guide

Phone or tablet

Each player opens their link in a browser and bookmarks it. Their character saves automatically and will be there next session.

Assign one seat per player. Do not share the same link between two players on the same device.

Seat 1 tavern-rpg.github.io/the-round/player1.html Seat 2 tavern-rpg.github.io/the-round/player2.html Seat 3 tavern-rpg.github.io/the-round/player3.html Seat 4 tavern-rpg.github.io/the-round/player4.html Seat 5 tavern-rpg.github.io/the-round/player5.html Seat 6 tavern-rpg.github.io/the-round/player6.html
The DM panel is built into every file. Any seat can run it.

Desktop or laptop

Open any player file directly in your browser. No setup needed.

  • Unzip the folder if you haven't already
  • Open player1.html (or whichever seat you're using) in Chrome, Firefox, or Edge
  • Your data saves locally in the browser between sessions
Desktop files work offline. Keep them in the same folder as this guide.

Activation

After purchase, go to your itch.io download page and click Request key. You'll receive a license key that looks like TVRN-XXXXXXXX-XX.

Share that key with your players before the session. Each player enters it once on their device when they first open their file. After that it's saved and they won't be asked again.

One key covers all six seats. Each device needs to enter it once.

First session

Each player will see a short setup screen when they open their file for the first time. It asks for a character name, class, and level. Takes about 30 seconds. After that the full sheet is ready.

Sending links to your players

iMessage, WhatsApp, Discord, email — any of these work. Send each player their specific seat link before the session so they can bookmark it ahead of time.

Something not working?

Contact us through itch.io and we'll sort it out.
